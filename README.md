## Reproduce the core results

Python 3.12 was used. Install the environment and run:

```text
python -m pip install -r requirements.txt
python reproduce.py
python reproduce.py --figures
```

The default workflow computes the exact duration identities and further seed
and reset checks, the spatial chain sums, the 30 Brownian width–rate cases,
and all 20 closed coefficient cells at 250 and 384 bits. It checks the entire
exponent–frequency rectangles and infinite tails. It does not infer an interval
result from sampled exponents. Generated calculation outputs go to `results/`.
The optional figure flag redraws Figs. 1–4, S4 and S7 from the supplied inputs.
The remaining supplemental figure PDFs and their scientific source data are
included; they are not all redrawn by that flag.

Additional calculations:

```text
python code/duration_ranks.py
python code/spectral_realization.py
python code/reset_duration_identity.py
python code/gate_perturbation.py
python code/entrance_resampling.py
python code/combine_finite_rates.py
python code/models/reaction_selection/exact_reaction_selection.py
python code/models/finite_controls/positive_criterion/positive_criterion.py --skip-scan
python code/models/finite_controls/positive_criterion/equal_mean_family_certificate.py
python reproduce.py --segments
```

`--segments` reevaluates the original 1558 near-Brownian coefficient cells and
is substantially more expensive. `code/cycle_enumeration.py` performs the full
cycle-mask search; `code/reset_response_certificate.py` evaluates the reset
response neighborhoods. These are separate from the default replay.

The full continuous-space Fourier solvers are under `code/models/finite_rate/`
and `code/models/extended_models/second_rate/`; their `solver/` directories
contain `green_energy_enclosure_safe_square.py` and
`run_derivative_certificate.py`. Run either with `--help` for witness, grid,
cutoff and precision options. Frozen cell/atom charges and potential enclosures
are supplied in the corresponding `continuum/` directories (the first rate
uses `code/models/continuous_space/rigorous_certification/continuum/`). These
large solves require substantially more time and memory than the default
replay. The finite-rate combiner only recombines their supplied enclosures.

Finite CTMC controls are in `code/models/reaction_selection/` and
`code/models/finite_controls/positive_criterion/`. The cell/lattice solver and
half-line FEM implementation are in `code/models/reproducible/`. Full spatial
resolution data are supplied in `data/figures/`, including the 93-grid table.

## Certified scope

- Original Pair II, no reset: coefficient gap greater than `2.72e-5` on the
  complete closed range `[1.9,2]`. The fractional localization theorem uses
  `[1.9,2)`; the Brownian endpoint has its own interpretation.
- Reset response: the certified continuous neighborhood remains
  `1.9982 <= alpha < 2`, `0 <= theta <= 1e-7`.
- Fractional finite-rate bounds apply only to the stated parameter points.
  The enlarged coefficient interval does not enlarge those finite-rate claims.
- Brownian finite-rate results concern the stated 30 grid points.
- Spatial scans and convergence slopes are numerical observations.

## Experimental context and third-party materials

Part X is a contextual prediction analysis, not experimental validation of the
constructed exact gate pairs or of their reaction correction.
Raw GlyR `.scn` records, MscL `.rda` records, their licenses and source locations
are included under `data/experimental/` and `data/experimental_sources/`.
The losslessly converted MscL arrays are supplied for the Python analysis.

```text
python code/experimental/analyze_glyr.py
python code/experimental/analyze_mscl.py
```

To regenerate the MscL arrays from R data files, install `pyreadr` and run
`python code/experimental/extract_mscl.py`.
The bundled dcio reader dependency and compatibility reader retain the MIT
license in `code/experimental/LICENSE_dcio.txt`. Original dataset licenses are
retained beside the raw records. Unused third-party paper PDFs are excluded.
Third-party materials retain their original licenses. No additional license has
been assigned to the authors' original code and data in this version.
